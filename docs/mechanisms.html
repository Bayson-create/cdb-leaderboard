Mechanism Robustness

The leaderboard scores one registered intervention (range-clip) across seven scenarios. This page asks a different question of the same reference stack: across every degradation mechanism that has been run at least at a pilot scale — how much of Safety, Comfort & handling and Operation survives, and where does the response first break?

Read this before the numbers. The four axes are not on a common severity scale and their scores are not comparable in magnitude to each other — only within-axis direction, rank and shape are meaningful across mechanisms. A planned shape / geometric-noise axis has no implementation anywhere in the stack (no point-jitter or range-noise injector exists) and is omitted rather than approximated. Cell sizes range from n=3 to n=17; several ladders (noted below) are excluded because they have no comparable nominal reference. Every number on this page traces to robustness_analysis_20260916 — see Provenance.

A second, independently-built cross-check of this page exists — computed from scratch without reading this page's code or numbers. It agrees on the red-light breakpoint and range-clip's starting sample size, and flags one open discrepancy on the NDT/localisation mediator (now resolved as measuring different variables).
